Hospedagem Gratuita Google Firebase (Plano Spark — R$ 0, sem cartão/depósito)

Sem Faturamento

O Google Cloud Run exige conta de faturamento (depósito de R$ 200), mas o Google Firebase (Plano Spark) usa o mesmo projeto mat-computacional-ufpr de forma 100% gratuita e sem pedir cartão ou depósito. Além disso, o app já realiza commits direto pela API do GitHub pelo seu navegador:

01. Abrir seu projeto no Firebase (Gratuito)

Acesse console.firebase.google.com, clique em Create a project (ou Add project) e selecione o seu projeto existente mat-computacional-ufpr. Ele entra direto no plano Spark (Grátis, sem cobrança).

02. Conectar seu Token do GitHub no App

Clique no botão Sincronizar GitHub no topo desta página e cole um Fine-grained Token do GitHub (permissão Contents: Read & Write). O token fica salvo só no seu navegador e permite gravar provas, horas e matérias direto da nuvem!

03. Links na Nuvem ativos
